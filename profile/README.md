# Fangst

Fangst is a self-hosted media platform written in Rust.

- **One download daemon** for torrent and usenet. It speaks the qBittorrent and
  SABnzbd APIs, so Sonarr, Radarr and friends can use it as it is.
- **A media manager** that keeps your files as they are: original filenames,
  NFO and JSON sidecars, and a documented API for any frontend.

Fangst is Danish for "the catch". It's in early development and not ready for use yet.
